# research/ —— 调研记录

这个目录是**设计与调研的原始记录**，不是产品文档。它们被保留下来，是因为
这份插件里几乎每一个设计决定背后都有一条外部证据或一次失败教训；删掉它们，
后来的维护者就只能看到结论、看不到理由，然后很容易把踩过的坑再踩一遍。

| 文件 | 内容 |
|---|---|
| `drift-signals-zh.md` | **中文信号词表**：从真实语料统计出的词与频次（不含原话引用） |
| `plan-drift-guard.md` | 立项前的调研：同类工具、学术与工程做法、以及它们各自缺什么 |
| `plan-evolution-priorart.md` | 计划演化（改计划不丢进度）的现成方案调研 |
| `plan-anchor-redteam.md` | **红队审计**：专门找绕过路径与"说了没做"之处 |

## 三条阅读提醒

1. **这些是当时的记录，不是现在的说明书。** 里面提到的本机事实（部署状态、文件行数、
   某个工具当时能不能用）**很可能已经变了**，不要据此判断当前状态。
2. **与实现不一致时，以实现为准。** 实现是 `dsh/lib/index.js`，不变量与判据以 `SPEC.md` 为准。
3. **原始语料与用户原话不在本仓库。** 词表只保留词与频次；红队记录里的路径、
   机器信息已做通用化处理。
